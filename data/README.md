# Dados

**Este projeto tem finalidade exclusivamente educacional e de portfólio.**

Os dados originais não foram incluídos neste repositório.

A base pode ser acessada no Maven Analytics Data Playground:

https://mavenanalytics.io/data-playground/bank-customer-churn

## Arquivos utilizados localmente

```text
Bank_Churn_Data_Dictionary.csv
Bank_Churn_Messy.xlsx
Bank_Churn.csv
```

A fonte disponibiliza uma versão limpa da base e uma versão com dados desorganizados para prática de limpeza. Neste projeto, foi utilizada a versão **desorganizada** como ponto de partida para realizar o tratamento dos dados com Python.

Para reproduzir a análise, baixe os arquivos na fonte oficial e coloque-os nesta pasta.
